# Deskloom

> 임시 이름입니다.

macOS와 Windows에서 똑같이 쓰는 바탕화면 꾸미기 앱입니다. 배경화면, 위젯, 화면을 돌아다니는 캐릭터를 한 앱에서 조합해 씁니다.

## 상태

개발 초기 단계입니다. 아직 내려받아 쓸 수 있는 버전은 없습니다.

## v1에서 만드는 것

- 정지 이미지 배경화면과 마우스에 반응하는 배경화면
- 화면 가장자리 서랍에서 꺼내 바탕화면에 놓는 위젯: 모래시계 타이머, 날씨 창문, 찢는 일력, 포스트잇
- 화면 바닥을 걸어 다니는 픽셀 캐릭터
- 배경과 위젯 배치를 "내 조합"으로 저장하고 바꿔 끼우기

항상 켜 두는 앱이라 가벼움을 기능만큼 중요하게 봅니다. 창에 가려지거나 전체화면 앱을 쓰는 동안에는 그리기를 멈추고, 배터리로 돌 때는 덜 그립니다.

## 지원 환경

- macOS 13 이상 (Apple Silicon, Intel)
- Windows 11 (Windows 10에서는 정지 이미지 배경만 쓸 수 있습니다)

## 만드는 데 쓰는 것

Tauri 2, Rust, TypeScript
